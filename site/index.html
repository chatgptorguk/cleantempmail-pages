网页邮箱和 API 都免费吗？+

网页临时邮箱免费、无需注册。API 面向自动化调用，独立密钥按请求额度一次性购买；共享测试密钥仅供体验。

API 是订阅制吗？可以充值吗？+

不是订阅，没有自动续订。每次购买生成一个独立密钥，额度不能追加到原密钥；需要更多额度时购买新密钥。

轮询空收件箱也会扣 API 额度吗？+

会。受保护 API 在密钥通过认证后即计次，空结果、重复轮询及部分处理错误仍会消耗额度。公开域名列表和剩余额度查询不扣额度。

能使用自己的域名吗？+

可以。按官网说明配置 MX 记录，并在自有域名入口提交验证。域名接入与可用情况以官网为准。

使用 CleanTempMail 需要注册吗？+

无需注册。直接访问官网即可创建免费临时邮箱，并在网页上查看收到的邮件。

可以选择邮箱域名吗？+

可以。官网提供多种可用域名供选择；具体域名及可用情况以官网实时显示为准。

临时邮箱适合长期使用吗？+

建议用于短期体验与测试。对于长期账户、重要资料和密码找回，使用你长期掌控的个人邮箱更合适。

为什么有的网站不接受临时邮箱？+

不同网站有自己的邮箱验证规则，部分服务会限制临时邮箱。请遵守对方的使用规则。

在这个页面可以直接收邮件吗？+

这是 CleanTempMail 的宣传页面。点击“免费创建临时邮箱”进入官网，即可使用实际的邮箱功能。
